# Global360

Enterprise Google Business Profile management for franchises, agencies, and multi-location brands.

## Features

- **Store Performance**: Analyze metrics, state performance, and location insights.
- **Rankings**: Monitor rankings over time, state rankings, and competitor comparison.
- **Reviews**: Unified review feed, response templates, sentiment categories, and executive reports.
- **Review Assistant**: QR code generator, AI review assistant, review logs, and options management.
- **Store Manager**: Manage location requests and store managers across regions.
- **Content**: Post Scheduler (Updates, Offers, Events) and photo asset governance.

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev
```
